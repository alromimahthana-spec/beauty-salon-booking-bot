# 💅 بوت حجز صالون تجميل
### ثناء | thanaa.codes

بوت يحجز مواعيد صالون التجميل بسهولة، يختار الخدمة واليوم والوقت، ويأكد الحجز.

## ✨ وش يسوي؟
- يعرض 6 خدمات: قص شعر، صبغة، استشوار، مكياج سهرة، مناكير، تنظيف بشرة
- يخلي الزبونة تختار اليوم والوقت المناسب
- يستلم اسم الزبونة ورقم جوالها
- يطبع تأكيد حجز كامل بالسعر

## 🚀 كيف تشغليه؟
python beauty-salon-booking-bot.py

## 💰 السعر
2500 ريال سعودي - نسخة كاملة للصالونات

## 📦 مثال على الحجز
الخدمة: مكياج سهرة
اليوم: الخميس
الوقت: 6 مساء
السعر: 200 ريال
